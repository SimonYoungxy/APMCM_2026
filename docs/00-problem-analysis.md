# 2026 APMCM 四题对比分析

> 结论先行：选 **C 题**。理由与全部依据见下文。

本文件记录选题阶段的判断，所有数据规模、缺失结构和事件数均为**实际打开数据包核对**所得，不是题面转述。

## 一、四题的数据事实

| 题目 | 实际数据 | 是否需要外部数据 |
|---|---|---|
| A 洪水遥感 | 1000 组 256×256 三联样本：灾前光学 RGBA、灾后 SAR 单波段 uint8、二值标签（0/1），解压约 395 MB | **需要**。第 3 问起要自采恒州（Hengzhou）灾前/灾中影像，第 4 问要人口、建筑、路网、医院、避难所、DEM |
| B 转炉炼钢 | 10 个 `.xlsb`，每个约 1400 行 × 2051 列（序号 + 2047 波长 + 累积氧耗 + CO₂ + CO），压缩 106 MB，展开约 2.9 亿个数值 | 不需要 |
| C 企鹅声学 | Data01 108×11、Data02 278×40、Data03–11 各 300×7，另附 3 段 wav 与 2 份官方 R 代码 | 不需要 |
| D 量子选材 | 训练 11,256 + 验证 3,969 = 15,225 行 × 22 列；测试 3,703 行无标签 | 不需要，但需 Kaiwu SDK 与 SPQC 算力申请 |

## 二、逐题判断

### A 题 洪水淹没识别与救援优化

- **优点**：第 1、2 问是标准语义分割，1000 张带标签小图足以训练 U-Net 类模型；题面已固定评价口径（像素精度、新增淹没面积误差、相对面积误差、空间重叠度），不用自己编指标。
- **风险**：第 3 问起要自己找 2026 年 7 月恒州的灾前/灾中影像，做跨传感器几何配准，再叠加人口、建筑、路网、避难所、地形。配准误差会直接让“新增淹没面积”这个核心数字失去意义，且这部分评分主观、难以自证。
- **判断**：除队内有遥感/GIS 经验外，不推荐。

### B 题 转炉炼钢双模态时序融合

- **优点**：数据自洽、零外部依赖；第 1、2 问是离群点剔除 + 连续重构 + 三维频谱 + 互相关估时延，性价比极高；“流速越大时延越小”给了现成验证信号。
- **风险**：第 3 问是用 2047 维火焰光谱实时预测 CO₂/CO，并要求跨 10 个炉次泛化。每炉仅约 1400 个时间点，跨炉域偏移明显，需要 PyTorch + GPU 与较长调参周期。
- **判断**：有深度学习经验和 GPU 就选它，否则第 3 问会拖垮全篇。
- **附注**：表头实际波长 339.39–1023.303 nm，与题面写的 340.535–1027.678 nm 不一致。数据仍是“序列 + 2047 波长 + 3 列目标”。

### C 题 企鹅海上声学通信与回放响应

- **优点**：数据小、干净、全部现成；官方附了 R 分析代码，等于给了“标准分析路径”；四问正好构成一条完整统计流水线（描述统计 → 非参数检验 → 分类器 → 单调衰减 + 阈值反解 + Bootstrap → GLM / 多项分布 / 生存分析），AI 写代码几乎零阻力，抽象材料几乎没有。
- **风险**：同质化严重。想出彩必须靠统计深度，而不是靠模型复杂度。
- **判断**：最稳，最符合“AI 好处理 + 容易上手 + 少抽象”的要求。

### D 题 量子计算在钙钛矿候选材料筛选中的应用

- **优点**：创新性最强，第 1 问是标准表格回归，做出来的人少。
- **风险**：与收益同源——**训练集 + 验证集 15,225 个样本中 V=0 的样本数为 0**，题面说的 19 个正样本全部位于无标签的 holdout。第 1 问因此是“零正样本 + 极端外推排序”，不是普通回归。第 2、3 问要把非线性代理模型二次化成 QUBO，还要满足量子硬件系数约束并申请算力。
- **判断**：只有队内有人愿意专门啃 Kaiwu SDK 与算力申请时才选。

## 三、按三条标准打分

判据来自需求：**AI 能更好处理数据、容易上手、减少抽象材料分析**。

| 维度 | A | B | C | D |
|---|---|---|---|---|
| AI 能代劳数据处理 | 高 | 中 | **极高** | 高（仅第 1 问） |
| 上手难度（越低越好） | 中 | 中高 | **最低** | 高 |
| 外部依赖风险 | **高** | 低 | 无 | **高** |
| 抽象材料占比 | 中 | 较低 | **最低** | **最高** |
| 完成度风险 | 高 | 中 | **最低** | 高 |
| 创新出彩空间 | 中 | 中高 | 中 | **最高** |

## 四、最终选择规则

- 想稳、想完整交付、想少碰抽象推导 → **C**
- 有深度学习与 GPU、想写技术含量更高的论文 → **B**
- 想赌创新、能接受高风险 → **D**
- 有遥感 / GIS 背景 → A，否则排除
