# v1 —— 初版写作指令

文件：`docs/instructions/v1-instruction.md`

## 内容

第一版把任务定义为「一次交付可预提交的完整论文」，包含：

- 角色设定（建模专家 + 统计专家 + LaTeX 专家）
- 输入材料清单（题面 PDF、数据目录、官方模板、官方 R 代码）
- 数据清单表
- 全局硬性要求（全英文、pdflatex 两遍、禁止编造、每个检验给统计量/p/效应量/CI、8–15 张图、可复现）
- 四问的解法深度（Q1 描述统计 + 非参数检验 + 随机森林；Q2 保真度 + AIC 选模 + Bootstrap 半径；Q3 logistic + 多项 logit + 生存分析；Q4 综合指数 + 敏感性）
- 交付物清单与自检清单

## 这一版存在的问题

经核查数据后确认，v1 有 4 处会导致产出错误，属于设计缺陷而非措辞问题：

| 问题 | 具体表现 |
|---|---|
| 数据泄漏未识别 | Q1 要求「随机森林 + 特征重要性」，但 F02 只在 tv 类有值（24/24），flat 与 mod 全缺（0/44、0/40）。照做会得到准确率虚高、且完全由缺失模式驱动的假模型 |
| 缺少可估性约束 | Q3 要求「Context + CallType + Distance + Npenguins 全上」，但 Approach 只有 23 个事件、Distance 有 13 个水平，模型必然不收敛或系数爆炸 |
| 漏掉官方 25 页上限 | 规范明确「main body within 25 pages」，v1 未提，容易写到 35 页以上被判违规 |
| 模板残留未处理 | 官方 `main.tex` 引用了不存在的 `cat` / `gongzhonghao` 两张图，直接编译会报 `File not found`；参考文献里还有 3 条 `\CJK` 中文条目，违反「全英文」 |

## 结论

v1 是一份「想法正确但不可执行」的指令：它要求的事情本身合理，但没考虑数据能不能支撑、模板能不能编译、页数会不会超标。
