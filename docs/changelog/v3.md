# v3 —— 加固可执行性，并加入附件策略

文件：`docs/instructions/v3-instruction.md`

## 相对 v2 的改动

| # | 改动 | 动机 |
|---|---|---|
| 1 | 模板清理从「按行号删除」改为 `grep -n` **按内容定位** | 行号会随任何编辑漂移；实测文件已被改过，v2 写的 198–200 实际是 199–201 |
| 2 | 工作目录改为工作区内 ASCII 子目录 `APMCM2026_C\`，并修正原因（风险来自 `-output-directory` / synctex / bibtex，而非直接 pdflatex） | 原写法指向工作区外，可能无权限；且「中文路径必挂」的论断不成立 |
| 3 | Q1 取消「两阶段判别模型」，改为在 Discussion 中用发声机理解释结构性缺失 | 避免产出一个准确率 1.00 的查表式假模型 |
| 4 | 新增 Q2 **阈值可达性规则**：阈值高于 4 m 处分位数时报「≤ 4 m，低于观测下限」，严禁调阈值凑可解 | 原版只要求「检查通过」，等于逼 agent 凑结果 |
| 5 | 新增 **阶段 −1 环境自检**（`pip freeze` → `env.txt`，逐项确认包可导入） | 避免阶段 3 卡在装包 |
| 6 | 新增 **阶段 6 收尾**（两遍编译 → 0 error → 核页数 → 核页眉 → 重命名 `C<队号>.pdf`） | 原流程写到正文就结束 |
| 7 | 序数模型补 **Brant 检验**、Cox 补 **Schoenfeld 残差检验** | 比例优势与 PH 假设必须检验并报告 |
| 8 | Data03–11 的 **1350 个 NaN** 写入指令，禁止 `dropna()` | 整行删除会改变各距离区间的样本构成 |
| 9 | 补 ControlSheet 交付说明：编译出 PDF 供打印，**签字扫描必须人工完成** | agent 不能代签 |
| 10 | 新增 **〇、附件策略**：不依赖任何聊天附件，禁止 base64 / url 内联文档源 | 修复 `API Error 400 ... only 'file' and 'text' document sources are supported` |
