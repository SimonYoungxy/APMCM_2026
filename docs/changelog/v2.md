# v2 —— 补上四条致命约束

文件：`docs/instructions/v2-instruction.md`

## 相对 v1 的改动

| # | 改动 | 解决 v1 的什么问题 |
|---|---|---|
| 1 | 新增「数据清单与已核实的缺失结构」整节，明确写出 F02 与 PulseRate 的缺失模式，并**禁止**把二者直接喂进分类器 | 数据泄漏 |
| 2 | 新增 Q3 的 **EPV ≥ 10** 约束：Approach 至多 2 个协变量，HeadsUp / Vocal 3–4 个；Distance 必须降维或分箱 | 模型不可估 |
| 3 | 硬性要求里加入「正文 ≤ 25 页，超出移入附录」 | 违反官方规范 |
| 4 | 新增「模板预处理」整节：删除不存在的推广图、删除 `\CJK` 中文参考文献、`\tihao{A}` 改 C | 第一次编译就挂 |
| 5 | 新增「分阶段交付流程」（阶段 0–5），每阶段落盘 `results/*.json`，最后一阶段由 JSON 回填正文 | 「禁止编造」不可执行 |
| 6 | 把「每个检验必须给效应量与 CI」改为「有公认实现时给出，不适用时说明原因」 | 原要求会逼出编造的效应量 |
| 7 | 加入随机种子 `42` 与包版本号要求 | 「一键复现」是空话 |
| 8 | 响应组合从 8 类多项 logit 改为 0–3 的序数模型 | 样本撑不住 8 类 |

## 这一版仍然存在的问题

| 问题 | 具体表现 |
|---|---|
| 硬编码行号 | 写的是「删除第 116–117 行」「198–200 行」，但文件被人改过，实际已偏移；换一份模板就完全失效 |
| 路径约束过严且位置不当 | 断言「必须不含中文路径」（实际中文路径下直接 pdflatex 是可以的），且指向工作区外的 `D:\Grade2_APMCM_C\` |
| 「两阶段判别」措辞有诱导性 | 要求「flat vs non-flat → mod vs tv」两阶段判别，但这两步本质是查表，照做会产出一个准确率 1.00 的假模型 |
| 阈值不可达无规则 | 只要求「可达性检查通过」，没说检查不通过怎么办，会逼 agent 调阈值凑结果 |
| 缺环境准备 | 直到阶段 3 才需要 lifelines，容易卡在装包 |
| 缺最终收尾 | 阶段 5 写完正文就结束，没有编译、页数核查与重命名 |
